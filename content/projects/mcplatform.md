Project Type: DevOps, Multi-Cloud, Self-Service platform for managing cloud infrastructure on all providers, devices and data centers

Date: 2019 - 2023

The platform simplifies the management of complex multi-cloud infrastructure by exposing easy to use UI and API to end users. Daiteap can manage Kubernetes clusters, virtual machines and S3 storage across a variety of cloud service providers, in-premise and IoT devices. Users can create integration multi-cloud environments by VPN, allowing Kubernetes nodes, virtual servers and devices to communicate directly without needing to cross edge network boundaries and use public IPs, gateways and proxies.
