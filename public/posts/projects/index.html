ALTERNATIVE

Project Type: Horizon 2020 research project

Date: 2021 - 2025

ALTERNATIVE will develop an innovative platform able to detect the cardiotoxicity of chemicals and their biotransformation products. The novel platform will enable regulators and industry to identify, quantify and prevent cardiotoxic co-exposures to industrial chemicals and pharmaceuticals in a cost-effective way. ALTERNATIVE will particularly focus on cardiotoxic effects on the older people, which is of high relevance in view of the aging European population and the high spread of cardiovascular diseases.

Our role

  • Within the scope of the project, we developed a cloud data platform that enabled the deployment, operation, and accessibility of machine learning models. The platform successfully facilitated streamlined data gathering and collaborative analysis among all ALTERNATIVE partners.
  • Development of web-based data exchange platform based on CKAN
  • Creation of custom CKAN extensions for: OIDC/SSO, S3 storage, Theming
  • Packaging and deployment of the platform with CI/CD automation
  • Integration of JupyterHub, CKAN and S3 with each other

Milestones

  • Implementation of Cloud Data Platform
  • Integration of ML model and data source into the cloud data platform

Multi-cloud management platform

Project Type: DevOps, Multi-Cloud, Self-Service platform for managing cloud infrastructure on all providers, devices and data centers

Date: 2019 - 2023

The platform simplifies the management of complex multi-cloud infrastructure by exposing easy to use UI and API to end users. Daiteap can manage Kubernetes clusters, virtual machines and S3 storage across a variety of cloud service providers, in-premise and IoT devices. Users can create integration multi-cloud environments by VPN, allowing Kubernetes nodes, virtual servers and devices to communicate directly without needing to cross edge network boundaries and use public IPs, gateways and proxies.

Technologies

  • Cloud - AWS, GCP, Azure, Alicloud
  • IaC - Terraform, Ansible
  • Kubernetes, Docker, Cluster-API, HELM, CEPH, Cert-manager, ArgoCD, Longhorn
  • IoT RaspberryPi
  • VueJS, HTML, CSS, JavaScript
  • RabbitMQ
  • Django und Python
  • CI/CD
  • PKI,OAuth2.0/OIDC, SSO, Keycloak,VPN IPSEC/WireGuard
